# Product Troubleshooting — TechGadgets Inc

## SmartWatch Pro X1

### Won't Turn On

1. Hold power button for 10 seconds (hard reset).
2. Connect to charger for at least 30 minutes — battery may be fully depleted.
3. Check if charging cable/pad is properly connected.
4. If still unresponsive after 1 hour of charging: likely hardware defect, arrange replacement.

### Bluetooth Not Connecting

1. Ensure Bluetooth is enabled on your phone.
2. Forget the device in phone's Bluetooth settings and re-pair.
3. Restart both the watch and the phone.
4. Ensure watch firmware is up to date (Settings > About > Software Update).
5. If persists: factory reset the watch (Settings > System > Reset).

### Battery Draining Fast

1. Check which apps are running (Settings > Battery > Usage).
2. Disable always-on display (saves ~40% battery).
3. Reduce notification frequency.
4. Update to latest firmware.
5. Normal battery life: 2-3 days with moderate use.

## Wireless Earbuds Z3

### One Earbud Not Working

1. Place both earbuds in charging case for 10 seconds.
2. Remove and check if both have LED indicator on.
3. Forget device in Bluetooth settings and re-pair.
4. If one earbud still silent: factory reset (hold touch sensor 15 seconds until LED flashes red).

### Poor Audio Quality

1. Clean ear tips — wax buildup affects sound.
2. Ensure proper fit (try different ear tip sizes).
3. Check if audio codec is set correctly in app (AAC recommended).
4. Move closer to connected device (range: 10 meters).

## PowerBank Ultra 20K

### Not Charging Devices

1. Try different USB cable.
2. Try different USB port on the powerbank.
3. Check if powerbank itself has charge (press button to see LED indicators).
4. Some devices require pressing the button to initiate charging.
5. If LED indicators don't light up even when plugged in: battery fault, arrange replacement.

## General Troubleshooting

- Always check for firmware/software updates first.
- Factory reset is a last resort — customer loses saved settings.
- If hardware defect is suspected and within warranty (1 year), arrange replacement.
- Out-of-warranty repairs: direct customer to authorized service centers.
