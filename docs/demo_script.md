# Demo Script

1. Baseline: ask a multi-intent question and show the limitation.
2. LLM: run the same question with the safety-first prompt.
3. RAG: ask a return-policy question and inspect retrieved evidence.
4. MCP: look up a valid and invalid order ID; show validation and graceful failure.
5. Safety/evaluation: submit an unsafe request, then run the evaluation page and inspect the failure-fix narrative.
